# AOSI research manuscript (arXiv preprint source)

- `main.tex` – manuscript (plain `article` class, pdflatex; figures drawn in TikZ, no external image files)
- `refs.bib` – bibliography (every entry checked against arXiv, Crossref, DataCite or the publisher's page on 9 Nov 2026)
- `main.bbl` – generated by BibTeX (`unsrtnat`); arXiv needs this file
- `main.pdf` – compiled output

Build: `pdflatex main && bibtex main && pdflatex main && pdflatex main`

arXiv upload: `/workspace/aosi-paper-arxiv.tar.gz` (main.tex + main.bbl + refs.bib).
