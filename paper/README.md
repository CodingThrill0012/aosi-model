# DAIRM research manuscript (arXiv preprint source)

"DAIRM: Divyendu's Data-State-Aware AI Reference Model for Generative AI Inference Systems", Divyendu Bhatt (independent researcher). This is the companion paper to the technical report [`docs/DAIRM-TR-0001.md`](../docs/DAIRM-TR-0001.md) (v2.0.0, which supersedes AOSI v1.2.1).

- `main.tex`: the manuscript (plain `article` class, pdflatex). All figures are drawn in TikZ from source, with no external or AI-generated images.
- `refs.bib`: the bibliography. Every entry was checked against arXiv, Crossref, DataCite, GitHub or the publisher's page on 9 Nov 2026.
- `main.bbl`: generated by BibTeX (`unsrtnat`). arXiv needs this file.
- `main.pdf`: the compiled output.

Build: `pdflatex main && bibtex main && pdflatex main && pdflatex main`

arXiv upload bundle: `dairm-paper-arxiv.tar.gz` (main.tex + main.bbl + refs.bib), built locally and not committed. It has not been submitted.

AI-assistance disclosure: AI tools helped with drafting, editing and formatting. The model, the design decisions and the final content are the author's.
