**Conventions**

- Name files `aosi-rfc-NNNN-<short-description>.<ext>`.
- Prefer Mermaid embedded in the RFC; when a binary figure (PNG/SVG) is needed, commit its editable source alongside it.
- Every asset MUST be traceable to the RFC section it illustrates and MUST use the canonical layer names from AOSI-RFC-0001 §4.2.
