# Assets

Diagrams and their source files for DAIRM-TR-0001. Every figure is drawn from source in this folder; no figure is an AI-generated image.

| File | Referenced by | Description |
|---|---|---|
| `dairm-overview.mmd` | `README.md`, DAIRM-TR-0001 §4.1 | Mermaid source of the overview: the six request-path layers (L6–L1), the boundary data states, and the Context Services, Build/Deploy and Management planes |
| `build_overview.py` | — | Python script (standard library only) that generates `dairm-overview.svg` |
| `dairm-overview.svg` | `README.md`, DAIRM-TR-0001 §4.1 | SVG overview generated by `build_overview.py`. Rebuild with `python3 assets/build_overview.py` |

**Conventions**

- Name files `dairm-<short-description>.<ext>`.
- Prefer Mermaid embedded in the Markdown. When an SVG or other rendered figure is needed, commit the source (Mermaid or a generating script) next to it.
- Every asset should be traceable to the section it illustrates and use the canonical layer, plane and data-state names from DAIRM-TR-0001 §4.
- Disclose any AI assistance in preparing a figure (see DAIRM-TR-0001 §12).
